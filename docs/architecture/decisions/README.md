## Status vocabulary

- **Proposed:** belum disetujui.
- **Accepted:** baseline keputusan; masih dapat belum diimplementasikan.
- **Superseded:** digantikan ADR lain.
- **Deprecated:** tidak lagi dianjurkan.

Perubahan keputusan membuat ADR baru atau menandai ADR lama sebagai superseded; jangan menghapus sejarah keputusan.
